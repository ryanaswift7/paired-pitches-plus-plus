# Phase 6: Portfolio Release

## Objective

Turn the validated analytical and decision workflows into a polished, reproducible portfolio project.

## Concrete objectives

- Integrate the data, descriptive, predictive, and prescriptive workflows.
- Build the final interactive application and application-facing query layer.
- Publish methodology, model-card, data-dictionary, and reproducibility documentation.
- Pin dependencies and document clean-clone setup and execution.
- Preserve configuration-driven data and model builds.
- Save diagnostics, posterior predictive checks, evaluation artifacts, and metadata.
- Add deterministic random seeds where supported.
- Publish final case studies and clearly state limitations.

## Planned case studies

- A pitcher with a highly effective fastball–breaking-ball combination
- A pitcher whose unusual pitch shapes create distinctive separation
- A pitcher for whom raw and adjusted sequence results disagree
- A state in which the system abstains because candidate pitches are too uncertain
- A comparison between deterministic pitch ranking and a regularized pitch mix

## Deliverables

- Polished interactive application
- Final methodology and model card
- Reproducible build and evaluation workflow
- Final report with one defensible baseball finding
- Case studies demonstrating descriptive, predictive, and prescriptive behavior
- Clear communication of assumptions, uncertainty, and limitations

## Definition of done

- A clean clone can follow the documented setup and reproduce the published artifacts.
- Raw tracking data is excluded from version control and source terms are documented.
- Every recommendation is inspectable from inputs through model output.
- The final project demonstrates reproducible data engineering, Bayesian modeling, calibration, decision analysis, and communication of uncertainty.
